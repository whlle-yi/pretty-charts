# 风格规范总纲（style-guide）

> 本文件是 pretty-charts 的单一风格事实来源：配色规则、字体、导出规格、防误导规则、三档自查清单都在这里。
> 数据图/非数据图的具体方法论在 `data/`、`diagram/` 下；主题资产在 `assets/`。

## 1. 设计哲学

**一张好图 = 读者在 5 秒内得到正确的信息，且不被形式干扰。**

优先级从高到低：**准确 > 易读 > 简洁 > 美观**。任何与高优先级冲突的美化都要舍弃。三个动作原则：

1. **先删后加**：默认删掉一切不承载信息的元素（边框、网格线、图例框、3D 效果、阴影），需要时再加回。
2. **墨水比**：每个元素问一句"删掉它信息会损失吗"，不会就删（data-ink ratio）。
3. **一致**：同一交付物内所有图共用一套主题（色板 + 字号 + 线宽），混用主题是最常见的低级失误。

## 2. 三档质量标准

| | T1 出版级 | T2 报告级 | T3 展示级 |
|---|---|---|---|
| 场景 | 期刊论文、学位论文、正式报告 | 咨询/商务报告、文档配图、邮件插图 | PPT、海报、社交媒体 |
| 默认主题 | academic | business | showcase |
| 画布 | 期刊栏宽决定（90/190mm） | 16:9 或版心宽度 | 16:9（PPT 页面等大） |
| 字号逻辑 | 印刷可读即可（最小 7pt） | 屏幕舒适阅读（最小 9pt） | 远距离可读（最小 11pt） |
| 线条 | 细（0.8–1.5pt） | 中（1–2pt） | 粗（2–2.5pt） |
| 位图 DPI | ≥600（线图 ≥1200 更佳） | 200 | 200 |
| 装饰余量 | 几乎为零 | 克制 | 可用强调色块/大标注 |

用户未指定档位时：学术语境 → T1，工作文档 → T2，演示/宣传 → T3。同一交付物内**所有图必须同一档位**。

## 3. 配色规则

三套色板（`assets/palettes/*.json`）是**唯一取色来源**，禁止临时凑色。

### 3.1 色板选择

| 色板 | 档位 | 特征 |
|---|---|---|
| academic | T1 | Okabe-Ito（色盲安全金标准），低饱和、印刷友好 |
| business | T2 | Tableau 10，蓝色锚定，专业克制 |
| showcase | T3 | Tol Vibrant，高饱和高对比，远距离清晰 |

### 3.2 使用规则

1. **类别色**（categorical）：每条数据系列按顺序取色，**优先用第一主色**做最重要的系列；前 4 色覆盖绝大多数场景。上限 = 色板容量（7–10），超了就做**小倍数图**或合并类别，绝不加色。
2. **顺序色**（sequential）：编码数量大小（热图、密度、连续色带），由浅到深单向映射；**禁用彩虹 jet**。
3. **发散色**（diverging）：编码对中心点的偏离（相关系数、正负差值），中心必须是"无意义点"（0、均值），两侧对称使用。
4. **中性灰**：背景参照、上年同期、不重要系列一律用 `neutral`，让主数据突出。
5. **色盲安全**：三套色板已校验。补充规则：不用红/绿单独编码关键信息（叠加形状/线型/标签冗余编码）；深浅差异要明显，别让相邻色深浅接近。
6. **语义色**（仅 T2/T3）：正面/负面、达标/预警用语义色——success `#2E7D32`、warning `#ED6C02`、danger `#C62828`、info `#0288D1`；T1 出版级不用语义色（印刷可能失真，用色板色 + 文字标注）。

## 4. 字体与文字

详见 `assets/fonts.md`。要点：中文思源黑体（Noto Sans SC）+ 西文/数字 Arial；最小字号 T1=7pt / T2=9pt / T3=11pt；层级 ≤4 级；强调用加粗与强调色，不用下划线和颜色堆砌；标题说结论不说变量名——写"销量三年翻番"，不写"2021–2024 年销量"。

## 5. 布局与导出规格

### 5.1 尺寸速查

| 交付场景 | 尺寸 | 备注 |
|---|---|---|
| 期刊单栏 | 90mm（3.54in）宽 | matplotlib figsize 直接用 |
| 期刊双栏 | 190mm（7.48in）宽 | |
| Word 文档配图 | 版心宽度 ≈ 15–16cm | |
| PPT 16:9 | 33.87×19.05cm，图按半页 15×8.4cm | T3 字号 |
| 网页/ECharts | 容器自适应，最小 320px 移动端可读 | 矢量导出 |

### 5.2 导出规则

1. **矢量优先**：PDF（印刷/投稿）、SVG（网页）；位图仅当交付渠道强制（PPT 内嵌 PNG、微信/社交媒体）。
2. 位图：T1 ≥600dpi，T2/T3 200dpi；白底；`bbox_inches='tight'` 且 pad ≤0.05in。
3. matplotlib 文字内嵌：`pdf.fonttype: 42`（TrueType 可编辑，主题已设）；SVG 用 `svg.fonttype: none`（依赖对方装字体，网页内嵌场景改 `paths` 或直接用 ECharts）。
4. 命名：`图名_主题_日期.png`（如 `sales_trend_business_20260926.png`），不用"新建图像.png"。

## 6. 防误导规则（红线，任何档位都不得违反）

1. **柱状图 y 轴必须从 0 开始**——柱高编码数量，截断等于撒谎。折线图可以截断（编码的是位置趋势）。
2. **不滥用双轴**：双轴只允许"单位相同的两个量"且两轴刻度对齐；不同单位的关联直接用双图 + 分色，并在标题中说明因果解读（相关 ≠ 因果）。
3. **截断必须显式**：任何非零起点的轴要加轴中断标记或在图注说明。
4. **不确定度不省略**：有误差/波动/样本量的数据必须有误差棒、置信带或箱线，并说明 n 与统计口径。
5. **样本归一**：比较不同规模的总体用比例/人均，不用绝对数制造"碾压"错觉。
6. **完整个体**：箱线/直方图隐藏了个体时，建议叠加散点（T1 论文越来越常见的审稿要求）。
7. **面积/圆角不编码**：饼图只用角度比较（且 ≤5 块，否则堆叠条形）；禁止 3D 饼图（透视扭曲角度）；气泡图面积 ∝ 数值（半径平方，不按半径线性）。
8. **图例完整**：每条线/每块色都有可对应的图例或直接标注（direct labeling 优先于图例）。
9. **图片不变形**：改尺寸等比例缩放，拉伸是最常见的事故。

## 7. 三档自查清单（画完逐项过）

### 7.1 T1 出版级
- [ ] 图型与分析目的匹配（比较/分布/构成/趋势/关系），选型依据可陈述
- [ ] 尺寸 = 目标期刊栏宽；字号 ≥7pt；线宽 ≥0.5pt
- [ ] 配色全部来自 academic 色板；灰度打印仍可分辨（叠加线型/标记冗余编码）
- [ ] 误差棒/置信区间齐全，图注含 n、统计检验、显著性标注规范（* p<0.05, ** p<0.01, *** p<0.001）
- [ ] 轴有单位；量级用科学记数或 SI 词头，不出现 1e6 这类裸记数
- [ ] 图注（caption）自含：不看正文也能懂这张图
- [ ] 导出 PDF 矢量、fonttype 42、600dpi 兜底 PNG

### 7.2 T2 报告级
- [ ] 标题/副标题说结论与口径（"Q3 华南区增速第一（+34% YoY）"）
- [ ] 关键数据有直接标注，读者不用拿尺子比对网格线
- [ ] 配色来自 business 色板，重要系列 = 主色，对照 = 灰
- [ ] 数字口径、单位、时间范围在图内可追溯
- [ ] y 轴从 0 开始（柱状）；无违规双轴
- [ ] 200dpi PNG 或 SVG，嵌入文档后文字仍 ≥9pt

### 7.3 T3 展示级
- [ ] 一页一结论：图表只承载一个信息点，删掉与结论无关的系列
- [ ] 最后一排观众可读：字号 ≥11pt 等效（按 PPT 页面比例），线宽 ≥2pt
- [ ] 标注直接放在数据旁（direct labeling），不用小图例
- [ ] 配色来自 showcase 色板，与页面模板不冲突；深色背景下检查对比度
- [ ] 动效克制（ECharts：仅入场动画，禁旋转 3D）
- [ ] 导出尺寸 = 插入位置等大，不缩放位图

## 8. 工作流约定（给 AI 的执行顺序）

1. 定性（数据图/非数据图）→ 定档（T1/T2/T3）→ 读 `data/chart-selection.md` 或 `diagram/` 对应文件
2. 加载对应主题资产；代码中显式引用主题文件，不硬编码样式常量
3. 作图 → 按 §7 对应清单逐项自查 → 修完再交付
4. 交付时说明：所用主题、档位、导出规格，以及用户可改的参数（尺寸/字号/色板）
