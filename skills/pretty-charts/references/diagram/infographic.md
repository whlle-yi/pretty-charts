# 信息图与海报（infographic）

> 一张图讲一个完整故事：数据 + 结构 + 文字的混合排版。归类的铁律：**按最终交付形态归这里，且两套规范（数据图防误导 + 非数据图布局）都要遵守。** 工具：SVG 手绘 / ECharts 页面 / PPT 排版，AI 生成用 SVG 或 HTML+CSS。

## 结构三段式

1. **标题区**：一句话结论做标题（"加班正在向低龄段转移"），10–14 字，副标题给口径（数据来源、时间范围）。
2. **主体区**：2–4 个视觉块，每块一个信息点，阅读动线 Z 字形/纵向分段；块与块用留白分隔，不用线框堆砌。
3. **落款区**：数据来源、制图、日期，字号最小但必须存在。

## 必守规范

1. **数字即主角**：关键数据放大 3–5 倍做"大数字块"（KPI 卡），图表只辅助表达趋势/构成。
2. **每块一个图型原则**：一块内不混多种图；全页图表 ≤3 张（信息图不是图表拼盘）。
3. **配色从主题色板取**：主色 + 强调色 + 中性灰三色叙事；底色浅色（或统一深色），正文字色对比度 ≥4.5:1。
4. **图标风格统一**：线性/面性二选一，同页不混；图标含义与文字相邻，不用悬停解释（静态交付）。
5. 防误导红线全部生效：百分比标注基数、柱状零起点、地图色标必备——**信息图的流量越大越不能歪**。
6. 尺寸按渠道：公众号 900×√n 长图、PPT 16:9、海报 A2/A1 150dpi 起步。
7. 文案层级 ≤4 级；中文字重用思源黑体 Medium/Bold 区分层级，不换字体家族。

## 常见错误

- ❌ 数据不标注来源与口径（可信度归零）
- ❌ 七八张小图表堆叠成"仪表盘截图"
- ❌ 装饰压过信息（渐变、3D、插画抢戏）
- ❌ 深色底 + 低对比正文（手机上看不清）
