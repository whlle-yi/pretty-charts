# 科研示意图（schematic）

> 机制示意图、装置图、实验流程、管线图。特征：**形状与空间关系本身承载含义**，需要精确几何控制。主力工具 TikZ（T1 出版级首选，见 `tool-tikz.md`），复杂插画用 SVG（`tool-svg.md`）。

## 图型清单

| 图型 | 适用 | 要点 |
|---|---|---|
| 机制示意图 | 反应机理、信号通路、因果链 | 实体+箭头+标注三要素；激活/抑制用箭头/短横区分 |
| 装置/结构图 | 实验装置、器件结构、几何构型 | 剖面线、比例、尺寸标注遵循工程制图惯例 |
| 实验流程图 | 材料与方法部分 | 与 flowchart.md 同规范，但强调可复现（参数进图注） |
| 示意管线图 | 数据/物料管线 | 与 architecture.md 数据流图同规范 |
| 坐标示意图 | 概念性曲线（示意趋势而非数据） | 必须在图注声明"示意，非实测数据"，轴可不标数但要素齐全 |

## 必守规范

1. **实体-箭头-标注三要素齐全**：每个箭头有起点终点和含义；含义写在箭头旁（"磷酸化"），不靠猜。
2. **激活/抑制/催化语义图标统一**：全场一套（如箭头=促进、T 形短横=抑制、圆点=催化），图注给图例。
3. **几何精确**：TikZ 用坐标与循环画阵列/网格，不用肉眼对齐；对称结构用 `scope` 镜像。
4. 字体与论文正文一致（XeLaTeX 全局字体方案），字号 ≥7pt；线宽 ≥0.5pt。
5. 黑白可辨：形状+线型+填充图案冗余编码，色盲与黑白打印双安全。
6. 分辨率无关：一律矢量（PDF/TikZ），投稿不交位图示意。
7. 风格与全文统一：同一篇论文的所有示意图共用线宽、箭头样式、配色（从 `references/style/palettes/academic.json` 取色）。

## 常见错误

- ❌ Word/Visio 手绘后截图（位图、字体与正文不一致、审稿大忌）
- ❌ 箭头含义不明（一条线上三种解读）
- ❌ 示意曲线配真实数据轴（误导成实测）
- ❌ 3D 效果装饰（期刊示意图 2D 表达，3D 只在必要维度存在时用）
