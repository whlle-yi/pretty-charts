# 趋势类（trend）

> 核心问题："随时间怎么变、变化多快、拐点在哪"。视觉通道首选**位置**（折线），时间必须等距落在 x 轴。

## 图型清单

| 图型 | 适用 | 关键规范 |
|---|---|---|
| 折线图 | 连续时间趋势（首选） | 系列 ≤4；线端直接标注系列名 |
| 多折线 + 灰化参照 | 主角系列 vs 对照 | 主角用主色，其余全部 neutral 灰 |
| 斜率图（slopegraph） | 只有两个时点 | 左右两列数值直标，删网格线 |
| 哑铃图（dumbbell） | 两时点 × 多类别的差 | 差值用强调色连线 |
| 面积图 | 单系列趋势+强调体量 | y 从 0；透明度 0.2–0.3 |
| 阶梯图（step） | 离散事件后水平维持（价格、费率） | where='post' |
| 对数轴折线 | 跨数量级增长（疫情、用户量） | 显式标注"对数刻度"；倍增速率视觉化为直线 |

## 必守规范

1. **时间轴等距**：数据点按真实时间定位；缺失日期留空或插值说明，**不能把不等间距的观测等距摆放**（如 1 月/7 月/8 月按三等分画）。
2. **系列 ≤4，超过拆小倍数**：4 条交错的线没有可读性。
3. **线端直标 > 图例**：`annotate` 在每条线末端标系列名 + 末值，读者不用对色找图例。
4. **折线可截断 y 轴**（编码的是位置不是长度），但截断必须显式标注。
5. 预测/估计值与实测值视觉分离：虚线 + 开口符号，图注说明。
6. 双轴：默认禁止。确实要用 → 两轴单位相同、刻度线对齐、两系列颜色与轴同色并在标题说明（详见 style-guide.md §6）。

## 常见错误

- ❌ 把不均匀间隔的日期等距画（趋势斜率失真）
- ❌ 折线图 + 双轴暗示因果（"搜索量与发病率同步上升"）
- ❌ 3D 折线（透视遮挡+角度失真）
- ❌ 每条线换个颜色但图例顺序与视觉顺序不一致
