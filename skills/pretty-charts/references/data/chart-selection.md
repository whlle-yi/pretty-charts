# 数据图选型决策树（chart-selection）

> 数据图 = 有"数值 → 视觉通道"映射的图。本文件回答"该画哪种图"；各图型的详细规范见同目录按分析目的拆分的文件。

## 0. 先问一句：需要图吗？

- 信息量 ≤3 个数字：**直接写进标题或正文**（"华南区 Q3 增速 34%，全区第一"），不画图。
- 图只是装饰、数据不支撑任何结论：不画。
- 数据图的价值 = 让"比较、分布、构成、趋势、关系"这些模式一眼可见。看不出模式的图没有存在意义。

## 1. 决策树：读者要回答什么问题？

```
读者的核心问题是什么？
│
├─ 谁大谁小？（比大小）────────────→ comparison.md
│   排序条形/柱状、分组柱、点图
│
├─ 数值是怎么分布的？（分布形态、离群值）→ distribution.md
│   直方图、密度、箱线、小提琴、ECDF
│
├─ 整体由什么构成？（占比、组成）───→ composition.md
│   堆叠柱/面积、饼/环（受限使用）、瀑布
│
├─ 随时间怎么变化？（趋势、走势）───→ trend.md
│   折线、斜率图、面积、哑铃图
│
├─ 两个/多个量有没有关联？（相关）──→ relationship.md
│   散点、气泡、相关矩阵、二维密度
│
├─ 层级/网络间怎么流动？（结构+量）─→ network.md
│   树图、桑基、弦图、力导向网络
│
├─ 在地图上哪里强哪里弱？（空间）───→ geo.md
│   choropleth、比例符号、流向
│
├─ 矩阵列间模式？（行×列密集数值）─→ heatmap.md
│   热图、日历热图
│
└─ 结论可信吗？（误差、显著性）────→ statistical.md
    误差棒、置信带、显著性标注、森林图
```

## 2. 快速对照表

| 你手上有什么 | 首选 | 备选 | 避免 |
|---|---|---|---|
| 类别 × 一个数值，比大小 | 排序条形图 | 点图 | 饼图、3D 柱 |
| 类别 × 多系列数值 | 分组柱状（≤3 系列） | 小倍数条形 | 雷达图 |
| 一个变量的分布 | 直方图 + KDE | ECDF、箱线 | 均值±SD 当"分布" |
| 多组分布比较 | 箱线/小提琴 + 叠加散点 | 山脊图 | 并排饼图 |
| 时间 × 一个数值 | 折线 | 面积图 | 柱状（多时段） |
| 时间 × 两时点对比 | 斜率图/哑铃图 | — | 双折线（两点时） |
| 构成随时间变化 | 堆叠面积图 | 百分比堆叠柱 | 多饼图并排 |
| 构成，静态、块数 ≤5 | 环图（中心放总量） | 100% 堆叠单条 | 饼图 >5 块、3D 饼 |
| 两数值变量 | 散点 + 趋势线 + CI | 二维密度（大数据） | 折线连散点 |
| 相关矩阵 | 发散色热图 | — | 数字表格（格子少时反而更清晰） |
| 流量/迁移 | 桑基图 | 弦图 | 力导向网络（边 >500 时） |
| 空间比率 | choropleth | 比例符号地图 | 绝对数上色 |
| 误差/显著性 | 误差棒/置信带 | 森林图（多研究） | 只给点估计 |

## 3. 选型三条铁律

1. **一种编码只回答一个问题**：想让读者比大小，就用位置/长度编码（条形），别用面积（饼）和颜色深浅（热图）——人眼对长度比较最准，角度次之，面积和颜色最差。
2. **系列数超过 4 就拆**：小倍数图（每个系列一张小图、共享轴）几乎总优于一张彩虹大图。
3. **先定档再画图**：T1/T2/T3 主题与清单见 `../style-guide.md` §2、§7。

## 4. 目的 × 档位联动的默认建议

- T1 论文：分布优先箱线/小提琴 + 散点（审稿人要看个体）；显著性标注规范见 `statistical.md`。
- T2 报告：标题直接写结论；关键数字直接标注在图上。
- T3 展示：一图一结论，系列数 ≤3，粗线大字。
