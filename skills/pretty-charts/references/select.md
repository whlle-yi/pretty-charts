# 选型（select）

> **只在「图型未定」时读本文件。** 用户已指定图型（"画个箱线图""来个流程图"）就跳过它，直接进 `SKILL.md` 第 2 步定档。
> 本文件只回答**该画什么图**；选定家族后，才去读对应的 `charts/<家族>.md`——那里才讲怎么画对。

## 1. 先问一句：需要图吗

**数据侧**
- 信息量 ≤3 个数字：**直接写进标题或正文**（"华南区 Q3 增速 34%，全区第一"），不画图。
- 图只是装饰、数据不支撑任何结论：不画。
- 数据图的价值 = 让"比较、分布、构成、趋势、关系"这些模式**一眼可见**；看不出模式的图没有存在意义。

**结构侧**
- 线性步骤 ≤4 步且无分支：编号列表通常比流程图更干净。
- 层级 ≤2 层、条目 ≤6：缩进列表或表格优先。
- 图的价值 = 拓扑结构（分支、循环、并行、依赖）**一眼可见**。

**一句话测试**：把内容压缩成"这张图要让读者 5 秒内得到 ______"。写不出 → 不适合画图。

**诚实原则**：内容里没有数据不建议数据图，没有结构不建议流程图；只有结论没有数字时先要原始数据。完整红线见 `spec.md` §红线与诚实原则。

## 2. 三分类探针

把数字都删掉，句子还成立吗？

- **成立** → 非数据图（结构/流程/概念）→ 见 §6
- **只剩数量关系还能看懂** → 数据图 → 见 §3
- **用数据讲一个结构化的故事** → 混合体（信息图、海报）：按**最终交付形态**归类，两边规范都遵守

## 3. 数据图：先定目的，再看要不要叠加修饰维度

**Q1 要表达什么模式（先选一个）**

| 目的 | 读者的问题 | 去读 |
|---|---|---|
| 比较 | 谁大谁小？ | `charts/compare.md` |
| 构成 | 整体由什么组成？ | `charts/compare.md` |
| 趋势 | 随时间怎么变？ | `charts/trend.md` |
| 分布 | 数值怎么分布？离群值在哪？ | `charts/distribution.md` |
| 关系 | 两个/多个量有关联吗？ | `charts/relationship.md` |
| 结构 | 层级/网络间怎么流动？ | `charts/structure.md` |
| 地理 | 差异发生在地理空间上 | `charts/map.md` |

**Q2 是否需要叠加修饰维度（可多选，与 Q1 组合）**

| 修饰 | 何时加 | 追加读 |
|---|---|---|
| 不确定度 | 需要表达误差、置信区间、显著性 | `charts/inference.md` |

**Q1 与 Q2 是叠加关系，不是单选。** 例："T1 双栏 + 趋势 + 带置信带" = `trend.md` + `inference.md` + `tools/python.md` + `spec.md`。

## 4. 快速对照表（跨家族横向比较）

拿不准该用哪一族时查这张表；决定了就按 §3 去读对应文件。

| 你手上有什么 | 首选 | 备选 | 避免 |
|---|---|---|---|
| 类别 × 一个数值，比大小 | 排序条形图 | 点图 | 饼图、3D 柱 |
| 类别 × 多系列数值 | 分组柱状（≤3 系列） | 小倍数条形 | 雷达图 |
| 一个变量的分布 | 直方图 + KDE | ECDF、箱线 | 均值 ± SD 当"分布" |
| 多组分布比较 | 箱线/小提琴 + 叠加散点 | 山脊图 | 并排饼图 |
| 时间 × 一个数值 | 折线 | 面积图 | 柱状（多时段） |
| 两离散时点 × 多类别 | 哑铃图 / 斜率图 | — | 双折线（两点时） |
| 构成随时间变化 | 堆叠面积图 | 百分比堆叠柱 | 多饼图并排 |
| 构成，静态、块数 ≤5 | 环图（中心放总量） | 100% 堆叠单条 | 饼图 >5 块、3D 饼 |
| 两数值变量 | 散点 + 趋势线 + CI | 二维密度（大数据） | 折线连散点 |
| 相关矩阵 | 发散色热图 | — | 数字表格（格子少时反而更清晰） |
| 流量 / 迁移 | 桑基图 | 弦图 | 力导向网络（边 >500 时） |
| 空间比率 | choropleth | 比例符号地图 | 绝对数上色 |
| 误差 / 显著性 | 误差棒 / 置信带 | 森林图（多研究） | 只给点估计 |

## 5. 选型三铁律

1. **一种编码只回答一个问题**：想让读者比大小，就用位置/长度编码（条形），别用面积（饼）和颜色深浅（热图）——人眼对长度比较最准，角度次之，面积和颜色最差。
2. **系列数超过 4 就拆**：小倍数图（每系列一张小图、共享轴）几乎总优于一张彩虹大图。
3. **先定档再画图**：档位由输出介质判定，见 `SKILL.md` 第 2 步。

## 6. 非数据图：按拓扑类型选

| 要表达什么 | 读 |
|---|---|
| 过程怎么走（步骤、分支、循环、泳道、时序、排期） | `diagrams.md`「流程与时序」 |
| 系统怎么组成（模块、分层、部署、数据流） | `diagrams.md`「系统架构」 |
| 概念怎么归类（发散、从属、分解、组织架构） | `diagrams.md`「层级与逻辑」 |
| 原理 / 机制怎么运作（科研示意、装置、管线） | `diagrams.md`「科研示意图」 |
| 一张图讲一个完整故事 | `diagrams.md`「信息图」 |

非数据图的通用布局规范（对齐、流向、节点文字、克制着色）在 `spec.md` §非数据图通用布局——所有非数据图共用，各图型节不重复。

## 7. 归属判定（跨文件的唯一裁决处）

| 图型 | 唯一归属 | 理由 |
|---|---|---|
| 哑铃图 / 斜率图 | `charts/compare.md` | 两**离散**时点 × 多类别的变化量是做比较；连续时间轴才归 `trend.md` |
| 树图 / 桑基 / 弦图 / 力导向 / 河流图 | `charts/structure.md` | 结构 + 数量。形似非数据图，但**面积/宽度编码数值**，故遵守数据图规范 |
| 相关矩阵 / 热图 / 日历热图 | `charts/relationship.md` | 形式主导 |
| 地图类 | `charts/map.md` | 空间维度，可与任何目的叠加 |
| 误差棒 / CI / 显著性 / 森林图 | `charts/inference.md` | **叠加规范**，不是独立图型 |
