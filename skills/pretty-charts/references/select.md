# 选型（select）

> **只在「图型未定」时读本文件。** 用户已指定图型（"画个箱线图""来个流程图"）就跳过它，直接进 `SKILL.md` 第 2 步定档。
> 本文件只回答**该选哪种图**。要不要画、怎么画对不在这里——「该不该画」见 `SKILL.md` 第 1 步，「图型 → 规范文件」见 `SKILL.md` 第 3 步。
> 选型的产出是「图型 + 备选」，不是文件路径。

## 1. 数据图：先定目的，再看要不要叠加修饰维度

**Q1 要表达什么模式（先选一个）**

| 目的 | 读者的问题 | 这一族管什么 |
|---|---|---|
| 比较 | 谁大谁小？大多少？ | 类别之间比大小：排序条形 · 柱状 · 分组柱 · 点图 · 哑铃 · 斜率 · 雷达（慎用） |
| 构成 | 整体由什么组成？ | 部分与整体：堆叠柱 · 100% 堆叠 · 环图 · 饼图 · 瀑布 · 漏斗（分阶段转化） |
| 趋势 | 随时间怎么变？ | 时间轴上的变化：折线 · 多折线+灰化参照 · 面积 · 堆叠面积 · 阶梯 · 对数轴 · 日历热图 · 凹凸图（多期排名） |
| 分布 | 数值怎么分布？离群值在哪？ | 单变量形态：直方 · KDE · Q-Q · 箱线 · 小提琴 · 蜂群 · ECDF · 山脊 |
| 关系 | 两个/多个量有关联吗？ | 变量间关联：散点（+趋势线+CI）· 分面散点 · 气泡 · 边际分布散点 · 二维密度/hexbin · 相关矩阵 · 热图 · 聚类热图 · 时间×类别热图 · 高亮表格 · 散点矩阵 · 平行坐标（变量 ≥4） |
| 结构 | 层级/网络间怎么流动？ | 结构与数量：树图 · 桑基 · 弦图 · 力导向 · 河流图 · 上下游/依赖图 · UpSet/韦恩（集合） |
| 地理 | 差异发生在地理空间上 | 空间差异：choropleth · 比例符号 · 小倍数 · 双变量 · 流向/迁移 · 密度热力图 |

> 本表是选型入口，不是全集；各族完整图型清单与专属规范以 `charts/<族>.md` 的「图型清单」为准。

**Q2 是否需要叠加修饰维度（可多选，与 Q1 组合）**

| 修饰 | 何时加 |
|---|---|
| 不确定度 | 需要表达误差、置信区间、显著性、配对前后变化、meta 合并效应、生存结局——与上面任一族**叠加**，不替代它 |

**Q1 与 Q2 是叠加关系，不是单选。** 例："趋势 + 带置信带" = 趋势族 + 不确定度族，两份规范都要读。

## 2. 快速对照表（跨家族横向比较）

拿不准该用哪一族时查这张表；决定了就按 §3 去读对应文件。

| 你手上有什么 | 首选 | 备选 | 避免 |
|---|---|---|---|
| 类别 × 一个数值，比大小 | 排序条形图 | 点图 | 饼图、3D 柱 |
| 类别 × 多系列数值 | 分组柱状（≤3 系列） | 小倍数条形 | 雷达图 |
| 一个变量的分布 | 直方图 + KDE | ECDF、箱线 | 均值 ± SD 当"分布" |
| 多组分布比较 | 箱线/小提琴 + 叠加散点 | 山脊图 | 并排饼图 |
| 时间 × 一个数值 | 折线 | 面积图 | 柱状（多时段） |
| 两离散时点 × 多类别 | 哑铃图 / 斜率图 | — | 双折线（两点时） |
| 构成随时间变化 | 堆叠面积图 | 百分比堆叠柱 | 多饼图并排 |
| 构成，静态、块数 ≤5 | 环图（中心放总量） | 100% 堆叠单条 | 饼图 >5 块、3D 饼 |
| 两数值变量 | 散点 + 趋势线 + CI | 二维密度（大数据） | 折线连散点 |
| 相关矩阵 | 发散色热图 | — | 数字表格（格子少时反而更清晰） |
| 流量 / 迁移 | 桑基图 | 弦图 | 力导向网络（边 >500 时） |
| 空间比率 | choropleth | 比例符号地图 | 绝对数上色 |
| 误差 / 显著性 | 误差棒 / 置信带 | 森林图（多研究） | 只给点估计 |
| 多变量（≥4 个数值）看个体与聚类 | 平行坐标 | 散点矩阵（SPLOM） | 雷达图、多张孤立散点 |
| 集合之间的关系/交集 | UpSet（>3 个集合） | 韦恩图（≤3 个集合） | 力导向图硬画集合 |
| 多期排名变化（≥3 期） | 凹凸图（bump） | 小倍数斜率图 | 多条折线画排名 |
| 样本分布 vs 理论分布 | Q-Q 图 | 直方叠加理论曲线 | 只报检验 p 值 |
| 分阶段转化（注册→付费等） | 漏斗图 | 逐级条形 | 饼图 |
| 高频词/标签展示 | 条形图（按频次排序） | 表格 | 词云（面积不编码、无法比较） |

## 3. 选型三铁律

1. **一种编码只回答一个问题**：想让读者比大小，就用位置/长度编码（条形），别用面积（饼）和颜色深浅（热图）——人眼对长度比较最准，角度次之，面积和颜色最差。
2. **系列数超过 4 就拆**：小倍数图（每系列一张小图、共享轴）几乎总优于一张彩虹大图。
3. **先定档再画图**：档位由输出介质判定，见 `SKILL.md` 第 2 步。

## 4. 非数据图：按拓扑类型选

| 要表达什么 | 图型 |
|---|---|
| 过程怎么走 | 流程图 · 时序图 · 状态图 · 甘特图 |
| 系统怎么组成 | 分层架构 · 部署拓扑 · 数据流 |
| 概念怎么归类 | 思维导图 · 组织架构 · 概念图 |
| 原理 / 机制怎么运作 | 机制示意 · 装置图 · 管线图 |
| 一张图讲一个完整故事 | 信息图 · 海报版式 |

非数据图的通用布局规范（对齐、流向、节点文字、克制着色）在 `diagrams.md` 开篇「通用布局」——所有非数据图共用，各图型节不重复。

## 5. 归属判定（跨文件的唯一裁决处）

| 图型 | 唯一归属（族） | 理由 |
|---|---|---|
| 哑铃图 / 斜率图 | **比较** | 两**离散**时点 × 多类别的变化量是做比较；连续时间轴才归**趋势** |
| 凹凸图（bump） | **趋势** | 排名只是 y 值，时间仍是主轴；只有两个时点时退化为斜率图（归比较） |
| 树图 / 桑基 / 弦图 / 力导向 / 河流图 | **结构** | 结构 + 数量。形似非数据图，但**面积/宽度编码数值**，故遵守数据图规范 |
| 相关矩阵 / 热图 | **关系** | 形式主导 |
| 日历热图 | **趋势** | 形式是热图，读者的问题却是"什么时候强/弱"（时间轴），故归趋势；色标与排序规范借用 `charts/relationship.md`「热图与矩阵类」 |
| 地图类 | **地理** | 空间维度，可与任何目的叠加 |
| 误差棒 / CI / 显著性 / 森林图 | **不确定度（叠加）** | 不是独立图型，与任一族叠加 |
