# 自查清单（checklist）

> 画完**逐项过**，发现问题先修再看下一项。档位定义见 [`routing.md`](routing.md) §1；红线见 [`spec/integrity.md`](spec/integrity.md)。

## 通用收尾（三档都要）

- [ ] 红线九条逐条无违反（`spec/integrity.md` §1）
- [ ] 所有颜色来自所选色板 JSON，**无色板外颜色**（`spec/color.md` §1、§4）
- [ ] 多图交付时，语义 → 颜色的映射全局一致（`spec/color.md` §5）
- [ ] 字号 ≥ 本档下限，且按**缩放后**的等效字号判断（`spec/type.md` §2）
- [ ] 矢量优先；DPI、尺寸符合本档与目标渠道（`spec/layout.md` §1、§2）
- [ ] 图落在项目专用目录、命名符合规范、无中间产物残留（`spec/layout.md` §3）
- [ ] 图注自含（`spec/integrity.md` §2）

## T1 出版级

- [ ] 图型与分析目的匹配，选型依据可陈述（[`selection.md`](selection.md)）
- [ ] 尺寸 = 目标期刊栏宽（90 / 190mm，或按目标期刊模板实测）；精确栏宽时**不使用** tight bbox
- [ ] 配色全部来自 academic 色板（TikZ 论文版为黑白灰单色，属合规特例）；**灰度打印仍可分辨**（叠加线型/标记冗余编码）
- [ ] 误差棒 / CI 齐全；图注含 n、统计检验、显著性标注规范
- [ ] 轴有单位；量级用科学记数或 SI 词头，不出现 `1e6` 这类裸记数
- [ ] 字体已按 `spec/type.md` §3 处理：XeLaTeX 不嵌 VF 字体；经 gs 管线时已换静态字体
- [ ] 导出 PDF 矢量 + 600dpi 兜底 PNG；`pdf.fonttype 42`

## T2 报告级

- [ ] 标题 / 副标题说结论与口径（"Q3 华南区增速第一（+34% YoY）"）
- [ ] 关键数据有直接标注，读者不用拿尺子比对网格线
- [ ] 配色来自 business 色板；重要系列 = 主色，对照 = `neutral`
- [ ] 数字口径、单位、时间范围在图内可追溯
- [ ] 柱状 y 轴从 0；无违规双轴
- [ ] 200dpi PNG 或 SVG，嵌入文档后文字仍 ≥9pt

## T3 展示级

- [ ] 一页一结论：删掉与结论无关的系列
- [ ] 最后一排观众可读：字号 ≥11pt 等效，线宽 ≥2pt
- [ ] 直接标注放在数据旁，不用小图例
- [ ] 配色来自 showcase 色板，与页面模板不冲突；深色背景下检查对比度
- [ ] 动效克制（ECharts 仅入场动画，禁旋转 3D）
- [ ] 导出尺寸 = 插入位置等大，不缩放位图
