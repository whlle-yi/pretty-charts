# relationship

## 关系类


> 核心问题："两个/多个量之间有没有关联、有多强、什么形状"。视觉通道首选**位置**（散点）。
> **横切规范只在本技能 `references/common.md` 定义一次**：红线九条见 [`../common.md`](../common.md)，取色见 [`../common.md`](../common.md)，字体字号见 [`../common.md`](../common.md)，尺寸导出与落盘见 [`../common.md`](../common.md)。本文件**只列本图型特有规范**，不复述上述任何内容。

### 图型清单

| 图型 | 适用 | 关键规范 |
|---|---|---|
| 散点图 | 两数值变量，n ≤2000 | 过绘（overplotting）必须处理：透明度 0.3–0.6 → 二维密度 |
| 散点 + 趋势线 + CI | 表达线性/非线性关系 | 趋势线 + 置信带（95%）；不外推出数据范围 |
| 分组散点 / 分面 | 加类别维度 | 组 ≤4；分面共享坐标轴 |
| 气泡图 | 加第三个量（面积） | **面积 ∝ 数值**（半径 ∝ 平方根）；气泡 ≤3 个量级差 |
| 边际直方图散点 | 同时看边际分布 | 主散点 + 上/右边际（jointplot） |
| 相关系数矩阵热图 | 多变量两两相关 | diverging 色板、中心 0；标注相关系数数值 |
| 二维密度/六边形 | 大 n（>2000）散点过绘 | sequential 色板；KDE 等高线备选 |
| 散点矩阵（SPLOM） | 3–6 个数值变量两两关系总览 | 对角线放单变量分布；只画上/下三角一半；变量 ≤6，超了拆图 |
| 平行坐标图 | 变量 ≥4 的个体对比与聚类形态 | 轴按语义排序（不放字母序）；先标准化量纲；线半透明防过绘；系列 ≤4 |

### 画法骨架

#### 散点 + 回归线 + 置信带

```python
xs = np.linspace(x.min(), x.max(), 100)                  # 拟合线只画在数据范围内
ax.fill_between(xs, yhat - conf, yhat + conf, color=PAL["primary"],
                alpha=0.18, lw=0, label="95% 置信带")     # 先画带，再画点，线在最上
ax.scatter(x, y, s=18, color=PAL["primary"], alpha=0.55, linewidths=0)
ax.plot(xs, yhat, color=PAL["accent"], lw=1.8, label="线性拟合")
ax.set_title(f"广告投入与销售额正相关（r = {r:.2f}，p < 0.001，n = {n}）")  # 标题带统计量
ax.legend(loc="upper left")
```
身份元素：置信带先画、拟合线后画、标题携带 r / p / n。按数据调整：n 大时散点 alpha 降或改六边形密度；非线性关系换多项式并注明阶数。

#### 相关矩阵热图

```python
im = ax.imshow(corr, cmap="RdBu_r", vmin=-1, vmax=1)     # 发散色板 + 对称区间
ax.grid(False)                                           # 关网格，防格线透过色块
ax.set_xticks(range(k), labels, rotation=30, ha="right") # 长标签斜排 30°，不转 90°
ax.set_yticks(range(k), labels)
for i in range(k):                                       # 格内标 r 值（k ≤20 时）
    for j in range(k):
        ax.text(j, i, f"{corr[i, j]:.2f}", ha="center", va="center",
                fontsize=8, color=深底白字/浅底深字)
fig.colorbar(im, ax=ax, shrink=0.8)                      # 色标必备
```
身份元素：RdBu_r + [-1, 1] 对称色标、格内数值、色标必备。按数据调整：格子 >20×20 去掉格内数值；行/列按聚类或语义排序，不用字母序。

### 必守规范

1. **相关 ≠ 因果**### 必守规范

1. **相关 ≠ 因果**：图标题/图注禁止因果表述，除非研究设计支持（RCT）。
2. 趋势线必须带置信带；多项式/样条拟合注明阶数与理由，防过拟合曲线。
3. 气泡图：半径平方编码，图注给参照气泡定标；气泡重叠用透明度 + 描边。
4. 相关矩阵：用 diverging 色板、色标固定 [-1, 1] 或对称区间；n 小于 30 时同时报告 p 值或不画。
5. 过绘是散点第一杀手：n 大必须降采样、透明化或密度化，否则只见黑团。

### 常见错误

- ❌ 散点间用折线连接（暗示有序关系）
- ❌ 气泡按半径线性编码（半径 ∝ 数值时，数值 3 倍差会被放大成 9 倍**面积**差；正确做法是半径 ∝ √数值，即面积 ∝ 数值）
- ❌ 双轴散点"展示相关"
- ❌ 在相关矩阵里用 sequential 色板（-0.8 和 0.8 深浅相同，语义丢失）

## 热图与矩阵类


> 核心问题："行 × 列的密集数值里藏着什么模式"。视觉通道 = 颜色深浅，**只用于读者确实要扫模式而非精确读数的场景**；格子少（<5×5）时直接给数字表格更诚实。
> **横切规范只在本技能 `references/common.md` 定义一次**：红线九条见 [`../common.md`](../common.md)，取色见 [`../common.md`](../common.md)，字体字号见 [`../common.md`](../common.md)，尺寸导出与落盘见 [`../common.md`](../common.md)。本文件**只列本图型特有规范**，不复述上述任何内容。

### 图型清单

| 图型 | 适用 | 关键规范 |
|---|---|---|
| 数值热图 | 相关矩阵、交叉表（行×列 ≥6） | 格内标数值（格子 ≤20×20 时）；色标必备 |
| 时间 × 类别热图 | 排班、频次矩阵 | 行/列按语义排序，不按字母序 |
| 聚类热图（clustermap） | 发现行列分组模式（基因、指标聚类） | 附树状图；说明聚类距离与联结方法 |
| 高亮表格（table with color） | 汇报中的精确数字 + 模式 | 数字为主、颜色仅辅助（T2 常用） |

### 必守规范

1. **色板语义**：数量大小 → sequential（由浅到深单向）；对中心偏离（相关、差值、z 分数）→ diverging 且**中心对齐 0**。这是热图第一条生死线。
2. **色标范围**：不被离群值拉伸（少数极值让其余全成白板）→ 用分位数截断（如 1%–99%）并注明；色标必须显示。
3. **行列排序**：按聚类、按行和/列和、按语义排序皆可，**唯独不要默认字母序**——排序才能让"块状模式"浮现。
4. 格内标注：T1 相关矩阵必须标 r 值；字号 ≥7pt；格子太小就只给色标。
5. 缺失值：显式灰色（或带纹理），不参与色标范围计算。
6. 大热图（>50×50）：关掉格线（linewidth 0），靠色块自然分隔。

### 常见错误

- ❌ 相关矩阵用 sequential 色板（-0.9 与 +0.9 无法区分）
- ❌ 色标被 1 个离群值拉满
- ❌ 彩虹 jet（感知不均匀，中部虚假亮带）
- ❌ 行列无意义的字母序（模式被切碎）
