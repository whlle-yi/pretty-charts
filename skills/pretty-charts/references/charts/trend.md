# trend

## 趋势类


> 核心问题："随时间怎么变、变化多快、拐点在哪"。视觉通道首选**位置**（折线），时间必须等距落在 x 轴。
> **横切规范只在本技能 `references/common.md` 定义一次**：红线九条见 [`../common.md`](../common.md)，取色见 [`../common.md`](../common.md)，字体字号见 [`../common.md`](../common.md)，尺寸导出与落盘见 [`../common.md`](../common.md)。本文件**只列本图型特有规范**，不复述上述任何内容。

### 图型清单

| 图型 | 适用 | 关键规范 |
|---|---|---|
| 折线图 | 连续时间趋势（首选） | 系列 ≤4；线端直接标注系列名 |
| 多折线 + 灰化参照 | 主角系列 vs 对照 | 主角用主色，其余全部 neutral 灰 |
| 斜率图（slopegraph） | 只有两个时点 | 左右两列数值直标，删网格线 |
| 哑铃图（dumbbell） | 两时点 × 多类别的差 | 差值用强调色连线 |
| 凹凸图（bump） | ≥3 期的排名变化 | 只编码排名不编码绝对值；线端直标系列名；期数多改小倍数 |
| 面积图 | 单系列趋势+强调体量 | y 从 0；透明度 0.2–0.3 |
| 阶梯图（step） | 离散事件后水平维持（价格、费率） | where='post' |
| 对数轴折线 | 跨数量级增长（疫情、用户量） | 显式标注"对数刻度"；倍增速率视觉化为直线 |
| 日历热图 | 按日期的强度（贡献、客流、签到） | 周为行、年为列；空缺用 `missing` 灰、与零（sequential 最浅端）区分；色标范围与行列排序规范借用同级 `relationship.md`「热图与矩阵类」 |

### 画法骨架

#### 折线图 + 线端直标 + 置信带

```python
for name, y, color in series:                            # 每系列一条线 + 95%CI 带
    ax.plot(x, y, color=color, lw=1.6)
    ax.fill_between(x, y - band, y + band, color=color, alpha=0.15, lw=0)
for name, y in series:                                   # 线端直标：名称 + 末值，图例可省
    ax.annotate(f"{name} {y[-1]:.0f}", (x[-1], y[-1]), xytext=(5, 0),
                textcoords="offset points", va="center", fontsize=8)
ax.set_xticks(x[::3], labels[::3], fontsize=8)           # 刻度稀疏化，防拥挤
ax.set_xlim(-0.4, x[-1] + 1.8)                           # 右侧留直标空间
```
身份元素：线端直标（系列名 + 末值）、置信带 alpha 0.15。按数据调整：系列 ≤4；x 刻度步长随密度；预测段用虚线 + 开口符号。

### 必守规范

1. **时间轴等距**：数据点按真实时间定位；缺失日期留空或插值说明，**不能把不等间距的观测等距摆放**（如 1 月/7 月/8 月按三等分画）。宽高比宜 3:1–2:1（宽大于高）；多面板共享时间轴时保持一致。
2. **系列 ≤4，超过拆小倍数**：4 条交错的线没有可读性。
3. **线端直标 > 图例**：`annotate` 在每条线末端标系列名 + 末值，读者不用对色找图例。
4. 预测/估计值与实测值视觉分离：虚线 + 开口符号，图注说明。

### 常见错误

- ❌ 把不均匀间隔的日期等距画（趋势斜率失真）
- ❌ 折线图 + 双轴暗示因果（"搜索量与发病率同步上升"）
- ❌ 3D 折线（透视遮挡+角度失真）
- ❌ 每条线换个颜色但图例顺序与视觉顺序不一致
