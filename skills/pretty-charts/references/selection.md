# 选型（selection）

> 本文件是**选型的唯一定义处**：该不该画、画数据图还是非数据图、画哪一种。
> 定档见 [`routing.md`](routing.md)；选定后的图型专属规范在 `references/data/` 与 `references/diagram/`。

## 0. 先问一句：需要图吗？

**数据侧**
- 信息量 ≤3 个数字：**直接写进标题或正文**（"华南区 Q3 增速 34%，全区第一"），不画图。
- 图只是装饰、数据不支撑任何结论：不画。
- 数据图的价值 = 让"比较、分布、构成、趋势、关系"这些模式**一眼可见**；看不出模式的图没有存在意义。

**结构侧**
- 线性步骤 ≤4 步且无分支：编号列表通常比流程图更干净。
- 层级 ≤2 层、条目 ≤6：缩进列表或表格优先。
- 图的价值 = 拓扑结构（分支、循环、并行、依赖）**一眼可见**。

## 1. 三分类探针

把数字都删掉，句子还成立吗？

- **成立** → 非数据图（结构/流程/概念）→ 看 §6。
- **只剩数量关系还能看懂** → 数据图 → 看 §2。
- **用数据讲一个结构化的故事** → 混合体（信息图、海报）：按**最终交付形态**归类，两边规范都遵守（数据侧红线 + 非数据侧布局）。

## 2. 数据图：先定目的，再看要不要加修饰维度

**Q1 要表达什么模式（五选一）**

| 目的 | 读者的问题 | 去读 |
|---|---|---|
| 比较 | 谁大谁小？ | `data/comparison.md` |
| 分布 | 数值怎么分布？离群值在哪？ | `data/distribution.md` |
| 构成 | 整体由什么组成？ | `data/composition.md` |
| 趋势 | 随时间怎么变？ | `data/trend.md` |
| 关系 | 两个/多个量有关联吗？ | `data/relationship.md` |
| 结构 | 层级/网络间怎么流动？ | `data/network.md` |

**Q2 是否需要叠加修饰维度（可多选，与 Q1 组合）**

| 修饰 | 何时加 | 去读 |
|---|---|---|
| 空间 | 差异发生在地理空间上 | `data/geo.md` |
| 密集行列 | 行 × 列的密集数值矩阵 | `data/heatmap.md` |
| 不确定度 | 需要表达误差、置信区间、显著性 | `data/statistical.md` |

**Q1 与 Q2 是叠加关系，不是单选。** 例："T1 双栏 + 趋势 + 带置信带" = `trend.md` + `statistical.md` + `tools/matplotlib.md` + `spec/type.md`。决策树只解决 Q1，别把 Q2 当成另一个互斥分支。

## 3. 快速对照表

| 你手上有什么 | 首选 | 备选 | 避免 |
|---|---|---|---|
| 类别 × 一个数值，比大小 | 排序条形图 | 点图 | 饼图、3D 柱 |
| 类别 × 多系列数值 | 分组柱状（≤3 系列） | 小倍数条形 | 雷达图 |
| 一个变量的分布 | 直方图 + KDE | ECDF、箱线 | 均值 ± SD 当"分布" |
| 多组分布比较 | 箱线/小提琴 + 叠加散点 | 山脊图 | 并排饼图 |
| 时间 × 一个数值 | 折线 | 面积图 | 柱状（多时段） |
| 两离散时点 × 多类别 | 哑铃图 / 斜率图 | — | 双折线（两点时） |
| 构成随时间变化 | 堆叠面积图 | 百分比堆叠柱 | 多饼图并排 |
| 构成，静态、块数 ≤5 | 环图（中心放总量） | 100% 堆叠单条 | 饼图 >5 块、3D 饼 |
| 两数值变量 | 散点 + 趋势线 + CI | 二维密度（大数据） | 折线连散点 |
| 相关矩阵 | 发散色热图 | — | 数字表格（格子少时反而更清晰） |
| 流量 / 迁移 | 桑基图 | 弦图 | 力导向网络（边 >500 时） |
| 空间比率 | choropleth | 比例符号地图 | 绝对数上色 |
| 误差 / 显著性 | 误差棒 / 置信带 | 森林图（多研究） | 只给点估计 |

## 4. 选型三铁律

1. **一种编码只回答一个问题**：想让读者比大小，就用位置/长度编码（条形），别用面积（饼）和颜色深浅（热图）——人眼对长度比较最准，角度次之，面积和颜色最差。
2. **系列数超过 4 就拆**：小倍数图（每系列一张小图、共享轴）几乎总优于一张彩虹大图。
3. **先定档再画图**：档位与色板见 [`routing.md`](routing.md) §1。

## 5. 归属判定（消除歧义）

这张表是**唯一裁决处**，图型文件不得给出不同归属：

| 图型 | 唯一归属 | 理由 |
|---|---|---|
| 哑铃图 / 斜率图 | `data/comparison.md` | 两**离散**时点 × 多类别的**变化量**是做比较；连续时间轴才归 `data/trend.md` |
| 树图 / 桑基 / 弦图 / 力导向 / 河流图 | `data/network.md` | 结构 + 数量。虽形似非数据图，但**面积/宽度编码数值**，因此遵守**数据图**规范 |
| 相关矩阵 / 热图 / 日历热图 | `data/heatmap.md` | 形式主导；`data/relationship.md` 只管散点/气泡/二维密度，相关矩阵只引用不重复 |
| 地图类（choropleth / 比例符号 / 小倍数） | `data/geo.md` | 空间维度修饰，可与任何目的叠加 |
| 误差棒 / CI / 显著性 / 森林图 | `data/statistical.md` | 是**叠加规范**，不是独立图型 |

## 6. 非数据图决策树

| 要表达什么 | 去读 |
|---|---|
| 过程怎么走？（步骤、分支、循环、泳道、时序、排期） | `diagram/flowchart.md`（含时序图）、`diagram/gantt.md` 见 flowchart.md 甘特图一节 |
| 系统怎么组成？（模块、分层、部署、数据流） | `diagram/architecture.md` |

| 原理/机制怎么运作？（机制示意、装置、管线） | `diagram/schematic.md` |
| 要在一张图里讲一个完整故事？ | `diagram/infographic.md` |

非数据图的通用布局规范（对齐、流向、节点文字、着色克制）在 [`spec/diagram.md`](spec/diagram.md)——所有非数据图共用，不在各图型文件里重复。
