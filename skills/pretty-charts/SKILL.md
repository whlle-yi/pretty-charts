# pretty-charts

四步：定性（画什么）→ 定档（给谁看）→ 加载规范 → 交付自查。规范按需读，不通读 `references/`。

## 设计原则

一张好图 = 读者 5 秒内得到正确的信息，且不被形式干扰。优先级：准确 > 易读 > 简洁 > 美观。

1. **先删后加**：默认删除不承载信息的元素（边框、网格线、图例框、3D、阴影），需要时再加。
2. **墨水比**：每个元素问一句"删掉它信息会损失吗"，不会就删。
3. **一致**：同一交付物内所有图共用一套主题与一套"语义 → 颜色"映射。

## 第 1 步：定性

**先做三条判断。用户已指定图型也要做——避免把不该画的画出来。**

1. **一句话测试**。把内容压缩成"这张图要让读者 5 秒内得到 ______"。写不出，就建议改用文字或表格。
2. **三分类分流**。把数字删掉，句子还成立 → 非数据图；只剩数量关系还能读懂 → 数据图；用数据讲结构化故事 → 混合体（按最终交付形态归类，两边规范都遵守）。这一步决定后面读 `charts/` 还是 `diagrams.md`。
3. **该不该画**。没有数据不画数据图，没有结构不画流程图；只有结论没有数字时先要原始数据。完整判据见 `spec.md` 的「红线与诚实原则」。

分流之后：

- **用户已指定图型** → 跳过选型，进第 2 步。
- **只给了内容** → 读 `references/select.md` 选型：目的 → 家族、跨家族对照表、非数据图拓扑选型、归属判定。

最后**输出推荐**：推荐图型 + 理由（指向内容中的哪个特征）+ 备选 + 待确认的数据缺口。经用户确认后进第 2 步；推荐被否说明核心信息提炼错了，回第 1 条重来。

## 第 2 步：定档

档位由输出介质决定。用户已说明档位则遵从；不确定就问，不要猜。

| 介质 | 档位 | 色板 | 主题资产 |
|---|---|---|---|
| 印刷，可能只有黑白 | T1 出版级 | academic | `assets/matplotlib/academic.mplstyle`、`assets/echarts/academic.json` |
| 屏幕文档，逐字阅读 | T2 报告级 | business | 上面两个文件，文件名换 `business` |
| 投影、远距离、一屏一结论 | T3 展示级 | showcase | 上面两个文件，文件名换 `showcase` |

本步产出就这两样：档位，以及该加载的主题资产。同一交付物内所有图同档同色板。

TikZ 例外：`assets/tikz/` 不按档位命名，也没有 business 模式，别去找 `assets/tikz/business.tex`。

字号、线宽、DPI、画布等数值参数不在本步查——第 3 步读 `spec.md` 时自然会用到；本步只需要上面那四个格子。

## 第 3 步：加载规范并作图

按序读：

1. `references/select.md` —— 仅当图型未定
2. `references/spec.md` —— 横切规范一次读完
3. 下表查出图型对应的规范文件
4. 工具文件，见下表
5. 找相近示例改：`examples/INDEX.md`

| 要画的图型 | 规范文件 |
|---|---|
| 条形 / 柱状 / 分组柱 / 堆叠 / 100% 堆叠 / 点图 / 哑铃 / 斜率 / 饼 / 环 / 瀑布 | `charts/compare.md` |
| 折线 / 面积 / 堆叠面积 / 日历热图 | `charts/trend.md` |
| 直方 / KDE / 箱线 / 小提琴 / ECDF / 山脊 | `charts/distribution.md` |
| 散点 / 气泡 / 二维密度 / hexbin / 相关矩阵 / 热图 | `charts/relationship.md` |
| 树图 / 桑基 / 弦图 / 力导向 / 河流图 | `charts/structure.md` |
| choropleth / 比例符号 / 小倍数地图 | `charts/map.md` |
| 误差棒 / 置信区间 / 显著性 / 森林图，叠加到上表任一族 | `charts/inference.md` |
| 流程图 / 时序图 / 状态图 / 甘特图 / 架构图 / 思维导图 / 示意图 / 信息图 | `diagrams.md` |

| 场景 | 工具文件 |
|---|---|
| 数据图 T1/T2 静态出图，matplotlib 为主 | `tools/python.md` |
| 数据图 T3 网页或交互，ECharts | `tools/web.md` |
| 非数据图交付级，TikZ，复杂有向图退 Graphviz，完全自定义退 SVG | `tools/tex.md` |

作图要求：

- 显式加载主题资产，禁止硬编码样式常量（色值、字号、线宽、DPI、figsize）。颜色只从 `assets/palettes/*.json` 取。
- 非数据图交付级用 TikZ，不用 mermaid。
- `\pcPaperMode` / `\pcPPTMode` 只切配色、线宽、字号，字体另用 `assets/tikz/fonts-serif.tex` 或 `fonts-sans.tex`。

## 第 4 步：交付

交付说明写三项：档位与主题、导出规格（矢量或 DPI、成品尺寸）、下列清单的逐项结论。

### 三档通用

- [ ] 九条红线无违反（`spec.md`「红线与诚实原则」）
- [ ] 颜色全部来自所选色板 JSON
- [ ] 多图交付时语义 → 颜色映射一致
- [ ] 字号达到本档下限，按缩放后的等效字号判断（`spec.md`「字体与文字」）
- [ ] 矢量优先，DPI 与尺寸符合目标渠道（`spec.md`「画布、尺寸、导出与落盘」）
- [ ] 图落在项目专用目录，命名规范，无中间产物残留
- [ ] 图注自含 n、统计口径、误差类型、显著性定义、数据来源

### T1 出版级

- [ ] 图型与分析目的匹配，选型依据可陈述
- [ ] 尺寸等于目标期刊栏宽（90 / 190mm，或按期刊模板实测）；精确栏宽时不用 tight bbox
- [ ] 配色全部来自 academic 色板；TikZ 论文版黑白灰单色属合规特例
- [ ] 灰度打印仍可分辨
- [ ] 误差棒或 CI 齐全，图注含 n、统计检验、显著性标注规范
- [ ] 轴有单位，量级用科学记数或 SI 词头，不出现 `1e6` 这类裸记数
- [ ] XeLaTeX 不嵌可变字体；经 Ghostscript 管线时换静态字体（`spec.md`「字体与文字」）
- [ ] 导出矢量 PDF + 600dpi 兜底 PNG，`pdf.fonttype 42`

### T2 报告级

- [ ] 标题或副标题说结论与口径，如"Q3 华南区增速第一（+34% YoY）"
- [ ] 关键数据直接标注，读者不必比对网格线
- [ ] 配色来自 business 色板；重要系列用主色，对照用 `neutral`
- [ ] 数字口径、单位、时间范围在图内可追溯
- [ ] 柱状 y 轴从 0，无违规双轴
- [ ] 200dpi PNG 或 SVG，嵌入文档后文字仍 ≥9pt

### T3 展示级

- [ ] 一页一结论，删掉与结论无关的系列
- [ ] 最后一排观众可读：字号 ≥11pt 等效，线宽 ≥2pt
- [ ] 直接标注放在数据旁，不用小图例
- [ ] 配色来自 showcase 色板，与页面模板不冲突，深色背景下检查对比度
- [ ] ECharts 只用入场动画，不用旋转 3D
- [ ] 导出尺寸等于插入位置，不缩放位图

### 环境缺失

按下列方式处理，并在交付说明里写明降级了什么。

| 缺什么 | 怎么办 |
|---|---|
| 无 XeLaTeX 或字体 | 先用 `xelatex --version`、`fc-list` 确认。TikZ 编译不了就问用户：装 TeX 发行版，或降级为 matplotlib 手绘示意图，降级产物标注"非交付级" |
| 无中文字体（Linux） | `apt install fonts-noto-cjk fonts-noto-cjk-extra fonts-texgyre` 后重试；用西文字体渲染中文会出豆腐块 |
| 只能出位图 | 至少 600dpi，交付说明写明"非矢量" |
| 缺地图数据 | 用仓库自带数据 `examples/data/geo/naturalearth_lowres.geojson` |
