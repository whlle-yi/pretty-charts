# pretty-charts —— 高质量绘图技能

**本文件是唯一入口，吸收了三件事**：设计哲学与四步契约、**选型**（画什么图）、**档位判定**（给谁看）。横切规范（红线/取色/字体/尺寸/非数据图布局）全在 [`spec.md`](references/spec.md)，图型与工具细则各读一份。

一次任务的标准读取量是 **4–5 个文件**：本文件 + `spec.md` + 一份图型文件 + 一份工具文件（+ 需要叠加时的第二份图型文件）。

## 设计哲学

一张好图 = 读者在 5 秒内得到正确的信息，且不被形式干扰。优先级 **准确 > 易读 > 简洁 > 美观**。

1. **先删后加**：默认删掉一切不承载信息的元素（边框、网格线、图例框、3D、阴影），需要时再加回。
2. **墨水比**：每个元素问一句"删掉它信息会损失吗"，不会就删。
3. **一致**：同一交付物内所有图共用一套主题，且"语义 → 颜色"的映射全局一致（`spec.md` §取色）。
4. **只定义一次**：横切规范只在 `spec.md` 定义，图型文件与工具文件只引用、不复述。

## 第 1 步：定性（画什么）

**用户已指定图型** → 跳过本节，直接进第 2 步。

**用户只给了内容** → 按顺序做完，不要默默开画：

1. **一句话测试**：压缩成"这张图要让读者 5 秒内得到 ______"。写不出 → 不适合画图，建议文字/表格。
2. **三分类探针**：把数字都删掉，句子还成立吗？成立 → **非数据图**；只剩数量关系还能看懂 → **数据图**；用数据讲结构化的故事 → **混合体**（按最终交付形态归类，两边规范都遵守）。
3. **选型**（下表）→ 4. **输出推荐**：`推荐图型 + 理由（指向内容中的哪个特征）+ 备选 + 待确认的数据缺口`，经确认后进第 2 步。推荐被否 = 核心信息提炼错了，回第 1 项重来。

### 数据图：先定目的，再看要不要叠加修饰维度

| Q1 要表达什么模式 | 读 |
|---|---|
| 比较（谁大谁小）· 构成（整体由什么组成） | [`charts/compare.md`](references/charts/compare.md) |
| 趋势（随时间怎么变） | [`charts/trend.md`](references/charts/trend.md) |
| 分布（分布形态、离群值） | [`charts/distribution.md`](references/charts/distribution.md) |
| 关系（两量关联）· 相关矩阵 · 热图 | [`charts/relationship.md`](references/charts/relationship.md) |
| 结构（层级、网络、流动） | [`charts/structure.md`](references/charts/structure.md) |
| 地理（空间差异） | [`charts/map.md`](references/charts/map.md) |

**Q2 修饰维度（可多选，与 Q1 叠加）**：需要表达误差 / 置信区间 / 显著性 → 追加 [`charts/inference.md`](references/charts/inference.md)。
Q1 与 Q2 是**组合关系而非互斥分支**——"趋势 + 不确定度"读 `trend.md` + `inference.md`。

### 非数据图

按拓扑类型读 [`diagrams.md`](references/diagrams.md) 的对应一节：过程怎么走（流程/时序/甘特）、系统怎么组成（架构）、概念怎么归类（层级/思维导图）、原理怎么运作（示意）、一张图讲完整故事（信息图）。

### 归属判定（跨文件的唯一裁决处）

| 图型 | 唯一归属 | 理由 |
|---|---|---|
| 哑铃图 / 斜率图 | `charts/compare.md` | 两**离散**时点 × 多类别的变化量是做比较；连续时间轴才归 `trend.md` |
| 树图 / 桑基 / 弦图 / 力导向 / 河流图 | `charts/structure.md` | 结构 + 数量。形似非数据图，但**面积/宽度编码数值**，故遵守数据图规范 |
| 相关矩阵 / 热图 / 日历热图 | `charts/relationship.md` | 形式主导 |
| 地图类 | `charts/map.md` | 空间维度，可与任何目的叠加 |
| 误差棒 / CI / 显著性 / 森林图 | `charts/inference.md` | **叠加规范**，不是独立图型 |

### 诚实原则（红线）

内容里没有数据不建议数据图，没有结构不建议流程图；只有结论没有数字时先要原始数据；两种图型难分伯仲时选**信息损耗更小**的一种。
**图注里出现的 n、置信区间、p 值必须由脚本真实计算，不得编造**（详见 `spec.md` §红线）。

## 第 2 步：定档（给谁看）

档位不是"学术 / 商务"这类社交标签——学术海报算学术还是演示？边界必然含混。**按输出介质的物理属性判**：

| 介质 | 档位 | 色板 | 主题资产 |
|---|---|---|---|
| **印刷**（可能只有黑白） | T1 出版级 | academic | `assets/matplotlib/academic.mplstyle` 等 |
| 屏幕文档，逐字阅读 | T2 报告级 | business | `assets/…/business.*` |
| 投影 / 远距离 / 一屏一结论 | T3 展示级 | showcase | `assets/…/showcase.*` |

**数值参数（字号层级、线宽、DPI、画布、位图下限）只在 [`spec.md`](references/spec.md) 出现一次**——档位差异已全部落进机器可读资产，换档只需换加载的资产，不要去改规范。
用户已说明档位则遵从；仍不确定就问一句，**不要猜**。
同一交付物内所有图必须**同档同色板**；多图交付还须做到语义 → 颜色全局一致。

## 第 3 步：加载文件并作图

```
1. 本文件（哲学 + 选型 + 档位）
2. references/spec.md                          # 横切规范，一次读完
3. references/charts/<家族>.md 或 diagrams.md   # 图型专属（+ 叠加时的第二份）
4. references/tools/<工具>.md                   # 工具专属
5. 作图 → 交付前回本文件「第 4 步」过清单
```

**工具选择**

| 场景 | 工具文件 |
|---|---|
| 数据图 T1/T2 静态出图（matplotlib / seaborn / plotly 探索） | [`tools/python.md`](references/tools/python.md) |
| 数据图 T3 网页 / 交互（ECharts / D3） | [`tools/web.md`](references/tools/web.md) |
| 非数据图交付级（TikZ / pgfplots，含何时退 Graphviz / SVG） | [`tools/tex.md`](references/tools/tex.md) |

**作图硬规则**：代码必须显式加载主题资产，**禁止硬编码样式常量**（色值、字号、线宽、DPI、figsize）；颜色只从 `assets/palettes/*.json` 读。
非数据图交付级一律 TikZ，**不使用 mermaid**。注意 `\pcPaperMode`/`\pcPPTMode` **只切配色、线宽、字号，不含字体**——字体用 `assets/tikz/fonts-serif.tex` 或 `fonts-sans.tex`（跨平台自动回退）。

## 第 4 步：交付

交付说明必须写明三项（都可核验）：**① 档位与主题；② 导出规格（矢量或 DPI、成品尺寸）；③ 下面清单的逐项结论。**

### 通用收尾（三档都要）

- [ ] 红线九条逐条无违反（`spec.md` §红线）
- [ ] 所有颜色来自所选色板 JSON，**无色板外颜色**
- [ ] 多图交付时语义 → 颜色的映射全局一致
- [ ] 字号 ≥ 本档下限，且按**缩放后**的等效字号判断（`spec.md` §字体）
- [ ] 矢量优先；DPI、尺寸符合本档与目标渠道（`spec.md` §画布与导出）
- [ ] 图落在项目专用目录、命名符合规范、无中间产物残留
- [ ] 图注自含（n、统计口径、误差类型、显著性定义、数据来源）

### T1 出版级

- [ ] 图型与分析目的匹配，选型依据可陈述
- [ ] 尺寸 = 目标期刊栏宽（90 / 190mm，或按期刊模板实测）；精确栏宽时**不使用** tight bbox（`spec.md` §画布与导出）
- [ ] 配色全部来自 academic 色板（TikZ 论文版黑白灰单色属合规特例）；**灰度打印仍可分辨**
- [ ] 误差棒 / CI 齐全；图注含 n、统计检验、显著性标注规范
- [ ] 轴有单位；量级用科学记数或 SI 词头，不出现 `1e6` 这类裸记数
- [ ] 字体已按 `spec.md` §字体处理：XeLaTeX 不嵌可变字体；经 Ghostscript 管线时换静态字体
- [ ] 导出 PDF 矢量 + 600dpi 兜底 PNG；`pdf.fonttype 42`

### T2 报告级

- [ ] 标题 / 副标题说结论与口径（"Q3 华南区增速第一（+34% YoY）"）
- [ ] 关键数据有直接标注，读者不用拿尺子比对网格线
- [ ] 配色来自 business 色板；重要系列 = 主色，对照 = `neutral`
- [ ] 数字口径、单位、时间范围在图内可追溯
- [ ] 柱状 y 轴从 0；无违规双轴
- [ ] 200dpi PNG 或 SVG，嵌入文档后文字仍 ≥9pt

### T3 展示级

- [ ] 一页一结论：删掉与结论无关的系列
- [ ] 最后一排观众可读：字号 ≥11pt 等效，线宽 ≥2pt
- [ ] 直接标注放在数据旁，不用小图例
- [ ] 配色来自 showcase 色板，与页面模板不冲突；深色背景下检查对比度
- [ ] 动效克制（ECharts 仅入场动画，禁旋转 3D）
- [ ] 导出尺寸 = 插入位置等大，不缩放位图

### 环境缺失时（降级路径）

**不要因为缺工具就默默出一张不合规的图**——按下面处理，并在交付说明里写明降级了什么。

| 缺什么 | 怎么办 |
|---|---|
| 无 XeLaTeX / 字体 | 先确认是否真缺（`xelatex --version`、`fc-list`）。TikZ 无法编译时**问用户**：装 TeX 发行版，或降级为 matplotlib 手绘示意图（降级产物必须标注"非交付级"） |
| 无中文字体（Linux） | `apt install fonts-noto-cjk fonts-noto-cjk-extra fonts-texgyre` 后重试；**不要**用西文字体硬渲染中文 |
| 只能出位图 | 至少 600dpi，并在交付说明写明"非矢量" |
| 缺地图 / 底图数据 | 用随仓库分发的数据（`examples/data/geo/naturalearth_lowres.geojson`）；不要静默改成非地图图型 |
